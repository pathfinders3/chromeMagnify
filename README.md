# chromeMagnify

마우스 커서 중심으로 **600×400 픽셀 렌즈** 영역을 **4배** 확대하는 크롬 확장 앱입니다.

## 사용 방법

1. 크롬에서 `chrome://extensions`를 열고 개발자 모드를 켭니다.
2. `압축해제된 확장 프로그램을 로드`를 눌러 이 폴더를 선택합니다.
3. 웹 페이지에서 마우스 오른쪽 버튼을 빠르게 두 번 클릭하면 확대 렌즈가 켜집니다.
4. 렌즈는 커서 주변을 따라다니며 300×200 영역을 4배 확대해 보여줍니다.
5. 마우스 왼쪽 클릭 또는 오른쪽 더블클릭으로 렌즈를 끕니다.

## 주의 사항

- 렌즈 활성화 시점의 화면을 캡처하므로, 렌즈가 열린 후 페이지 내용이 바뀌어도 렌즈에는 반영되지 않습니다.
- `chrome://` 등 브라우저 시스템 페이지에서는 동작하지 않습니다.
